# NVIDIA homepage — unofficial concept redesign

A scroll-driven 3D redesign of the NVIDIA homepage: one GPU becomes a blueprint, then a 1,024-GPU AI factory. This is a design concept only. It is not affiliated with, endorsed by or connected to NVIDIA Corporation. NVIDIA and related product names are trademarks of NVIDIA Corporation.

Built with Three.js, GSAP and Lenis. Static files, no build step.

- Add `?demo` to the URL to auto-scroll the page (for screen recording).
- Add `&cursor=0` to hide the custom cursor.
